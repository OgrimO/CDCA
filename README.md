# Collateral Damage Constrained Backdoor Attacks on Graph Neural Networks [IJCAI26]
Offical implementation of CDCA

To reproduce the results reported in the paper, run the scripts [backdoor.sh](CDCA/backdoor.sh)

- If you want to run the code on a specific GPU, specify it via the optional argument `--device_id=`

- If you want to run the code with defense and CDCA-D, change the optional argument `--defense_mode` and `--use_ood_detector`
 
This Implementation is built upon [SPEAR](https://github.com/yhDing/SPEAR)
